Ao salvar, a captura desta câmera é reiniciada em alguns segundos. As outras câmeras não são afetadas.
Vira o nome da pasta em disco e da rota RTSP. Não pode ser alterado depois.
192.168.0.10:5000  —  onde a câmera atende ONVIF. Ou dvrip://192.168.0.10:34567, e aí o servidor abre uma conexão só para o comando — é o que dá PTZ a uma câmera que grava por RTSP. Deixe vazio se ela não se move, ou se ela já grava por dvrip: nesse caso o comando vai pela própria conexão de vídeo. Procurar testa as portas comuns de ONVIF a partir do servidor.
