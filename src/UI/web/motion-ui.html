Ajuste fino
Cena nova acima de —
Mudança que toma o quadro inteiro — luz acendendo, infravermelho entrando, câmera empurrada — não é movimento. Acima deste valor o quadro é descartado em vez de virar evento.
Grade da análise
O detector não compara pixels: ele reduz cada quadro a uma grade e compara o cinza médio de cada célula. Grade mais grossa cega o detector para o que tem pouco contraste: um vulto pequeno precisa levantar a média de uma célula quatro vezes maior, e se ele for discreto não chega. Um vulto pequeno e bem claro continua passando — e chega a pesar mais, porque a conta é a fração de células acesas.
Mudança de cinza por célula —
Quanto o cinza médio de uma célula precisa mudar (de 0 a 255) para ela contar como mexida. É este o ajuste para a oscilação do infravermelho: quando o ganho automático clareia a cena inteira, todas as células andam juntas alguns níveis — reduzir a grade não ajuda nisso, porque a média desloca junto. Subir o valor faz o detector ignorar esse deslocamento; o preço é não ver movimento de pouco contraste.
Uma análise a cada
Quanto menor, mais fino o detector enxerga — e mais vídeo o servidor precisa decodificar. Movimento mais curto que este intervalo pode passar sem ser visto.
